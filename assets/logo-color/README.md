# Kothar · logotipo a color

![Kothar](kothar-logo.svg)

Esta carpeta es una versión derivada. El logotipo original, tal como lo entrega kothar, está en [`../logo/`](../logo/) en negro, blanco y grises. Los colores de aquí salieron después, al diseñar el README del repositorio: es la paleta «Plano técnico», elegida para ese README. Si la paleta cambia, se vuelve a derivar desde `../logo/kothar-mark-mono.svg` y `../logo/kothar-logo-mono.svg`; el logotipo no cambia.

## Archivos

| Archivo | Úsalo para |
|---|---|
| `kothar-mark.svg` | el logotipo a color, sobre fondos claros |
| `kothar-mark-on-dark.svg` | el logotipo sobre fondos oscuros |
| `kothar-logo.svg` | logotipo + nombre, sobre fondos claros |
| `kothar-logo-on-dark.svg` | logotipo + nombre, sobre fondos oscuros |
| `favicon.ico`, `favicon.svg` | icono de pestaña del navegador |
| `apple-touch-icon.png` | icono de pantalla de inicio, 180 px, sobre el fondo claro |
| `png/kothar-mark-16…512.png` | copias en píxeles del logotipo |
| `png/kothar-logo-800.png`, `-1600.png`, `-on-dark-1600.png` | copias en píxeles de logotipo + nombre |
| `og-image.png` | imagen de vista previa de enlaces, 1200 × 630 |
| `colors.css`, `tokens.json` | los colores como variables CSS y como datos |

Las versiones en una sola tinta, la animada y el nombre solo están en `../logo/`.

## Colores · Plano técnico

| Papel | Hex |
|---|---|
| Primario (forma principal) | `#0B1622` |
| Acento (el punto) | `#0B7FD0` |
| Fondo claro | `#F3F6FA` |
| Fondo oscuro | `#0A1420` |
| Neutro | `#7F8B99` |
| Primario, sobre fondos oscuros | `#F3F6FA` |
| Acento, sobre fondos oscuros | `#4DA8F0` |

Contraste medido: el primario sobre el fondo claro tiene 16.8:1 y sobre el oscuro 17.1:1; el acento, 3.9:1 sobre el claro y 7.2:1 sobre el oscuro.

## No se debe

- recolorearlo con colores que no sean de esta paleta o de la siguiente que elijas para el proyecto
- dar a las dos partes colores tan parecidos que dejen de distinguirse
- estirarlo, girarlo, contornearlo ni añadirle sombras o degradados
- redibujarlo ni reconstruirlo con una fuente

Los tamaños, la zona de respeto y la idea del logotipo están en [`../logo/README.md`](../logo/README.md).
