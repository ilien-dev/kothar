# kothar · brand

Concept B, "Three passes": a raw block refined in passes until it is round. A sharp square, two squares with softer corners and an orange disc, the piece you choose.

## Colour

| Name | HEX | Use |
|---|---|---|
| Orange | `#F04E15` | The disc, surfaces |
| Burnt orange | `#B83A0B` | Small text and lines on light grounds |
| Ink | `#141619` | Tiles, the name, text |
| Paper | `#ECEEF0` | Light grounds |
| Aluminium | `#C9CDD2` | Secondary surfaces |

Contrast: ink on paper 15.6:1 · ink on orange 5.0:1 · orange on ink 5.0:1 · orange on paper 3.1:1 (marks and large type only) · burnt orange on paper 4.9:1 · orange on aluminium 2.3:1 (never).

## Type

Space Grotesk 700 for the name and headings (tracking −0.045em), Inter for text, JetBrains Mono for code and labels. All under the SIL Open Font License.

## Rules

- **Minimum size:** symbol 16 px (small cut below 32 px); horizontal lockup 150 px wide.
- **Clear space:** one unit, half a tile (36 of the symbol's 256), on every side.
- **Lockup:** the name's x-height equals the disc; the gap between symbol and name is one unit.
- **Grounds:** colour version on paper or white; on-dark version on ink; one-ink versions anywhere else.
- **Do not:** stretch, rotate, recolour the disc, put orange on aluminium, set the name in another font, or rearrange the four parts.

Before public use, run a trademark search.
